Principle of Superposition

y(t) = y1(t) + y2(t)

For two equal-amplitude sine waves of the same frequency with a phase difference φ:

y1 = A·sin(ωt)
y2 = A·sin(ωt + φ)

At φ = 180° (π radians):

A·sin(ωt) + A·sin(ωt + π) = 0

Timbre & Harmonics (Fourier Theory)

> Why do shapes sound different?

Fourier series represent periodic waveforms as sums of sinusoidal components at a fundamental frequency and its harmonics. The ideal waveforms below have these characteristic harmonic patterns:

  • Sine: Only the fundamental frequency. Clean and smooth.
  • Triangle: Odd harmonics, with amplitudes decreasing approximately as 1/n².
  • Square: Odd harmonics, with amplitudes decreasing approximately as 1/n.
  • Sawtooth: All integer harmonics, with amplitudes decreasing approximately as 1/n.

How Fourier Synthesis Works

Fundamental: The first component has frequency f0. The higher components are harmonics at integer multiples 2f0, 3f0, and so on.

Waveform shape: Changing the relative amplitudes and signs (phases) of the harmonic components changes the resultant waveform. The spectrum bars show coefficient magnitudes; the signed number boxes also let you change phase by 180° through a negative coefficient.

Model limitation: This lab displays nine harmonics. Ideal square, triangle and sawtooth waves require infinitely many harmonics, so the presets are finite approximations.

How to Read These Displays

Time domain: Shows how the signal amplitude changes with time.

Frequency spectrum: The Fast Fourier Transform (FFT) estimates the frequency components present in the selected audio. The displayed bars represent relative spectral level, not a calibrated sound-pressure measurement.

Spectrogram: Repeated FFT measurements are plotted over time. Horizontal position represents time, vertical position represents frequency, and colour represents relative signal level.

Pitch estimate: The readout uses a simple autocorrelation estimate. It is most reliable for clear, approximately periodic sounds; complex or noisy audio may produce an unstable estimate.

Sampling and Quantisation

Sample rate: The number of samples taken per second. For a band-limited signal, the sampling rate must be greater than twice the highest frequency of interest to avoid aliasing (the Nyquist criterion).

Bit depth: Determines the number of possible quantisation levels. This demonstration uses a uniform quantiser over the normalised amplitude range from −1 to +1.

Model limitation: The display and sound use a simple sample-and-hold model without an anti-aliasing filter or reconstruction filter. It is an educational illustration, not a complete audio ADC/DAC chain.

How Timbre Changes a Sound

Fundamental: Sets the note's perceived pitch. Harmonics: Add integer multiples of the fundamental and shape the timbre. A sine tone contains only the fundamental; ideal square and triangle waves contain odd harmonics; a sawtooth contains all integer harmonics. These presets use a finite set of nine harmonics, so they are approximations.

Idealised Signal-Path Limitations

> Idealised Digital Phase Cancellation

Load the track or upload an audio file and click Play. Enable Phase Inversion to add a delayed, inverted copy of the same digital signal to the original. With equal levels and zero added delay, the two copies cancel in this idealised signal path. This demonstrates superposition; it is not a model of a headphone system cancelling sound in a room or at the ear.

> The Effect of Added Signal Delay

Increase the Added Signal Delay. The inverted copy is now shifted in time relative to the original. The phase shift produced by a delay depends on frequency: φdelay = 360° fτ. Consequently, some frequency components may be partly cancelled while others may be reinforced. This control applies an artificial delay of up to 2 ms; it does not measure your computer's actual processing or operating-system latency.

Live Microphone Loopback Demonstration

> Demonstrating Digital Phase Inversion

With headphones on and volume low, start the microphone. Speak or snap your fingers to view the captured signal. Enabling Add Inverted Copy mixes a delayed, inverted copy of that same microphone signal with the original in the browser audio output. This is a digital loopback experiment in superposition, not active cancellation of sound in the room or a working headphone ANC system. The added-delay slider is an artificial 0–2 ms delay; actual device and browser latency is separate and is not measured by this page. Microphone access requires browser permission and a secure context (for example, an HTTPS-hosted page or localhost).
